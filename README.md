📌 About This Project

This repositorycontains my reproduction, experimentation and implementation of a dementia risk prediction framework based on recursive logistic regression combined with explainable artificial intelligence (XAI) techniques.
The goal of this project is to understand how and what all clinical variables/ parameters that contribute to dementia risk more and to provide interpretable model explanations that support medical decision-making.

📚 Original Research Work

Title: A novel integrated logistic regression model enhanced with recursive feature elimination and explainable artificial intelligence for dementia prediction
Authors: Rasel Ahmed, Nafiz Fahad, Md Saef Ullah Miah, Md. Jakir Hossen, Md. Kishor Morol , Mufti Mahmud,  M. Mostafizur Rahman
Source: https://doi.org/10.1016/j.health.2024.100362

All credit for the original methodology and scientific contribution belongs to the respective authors.
This implementation is performed solely for academic learning and experimentation.

🧠 My Contribution

- Reimplemented the recursive logistic regression–based prediction pipeline in Python
- Performed clinical data preprocessing, feature selection using RFE
- Applied model training and validation for dementia risk classification
- Used SHAP-based explainability to interpret feature importance and prediction behavior
- Documented the complete reproducible workflow
